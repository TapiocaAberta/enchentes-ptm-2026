# Enchentes na Região do Putim — Site (GitHub Pages)

Site estático com dois documentos sobre enchentes na região do Putim (SJC):

- `index.html` — página inicial com links para os dois documentos
- `plano_enchentes_putim_2027.html` — Plano da Prefeitura para 2027 (obras 2025/2026)
- `relatorio-obras-anti-enchente-regiao-do-putim.html` — Relatório de obras anti-enchente (pesquisa no Diário do Município)
- `.nojekyll` — impede que o Jekyll processe os arquivos (necessário em projetos GitHub Pages)
